# Traver

> Every great trip deserves the right company.

Traver is a platform that connects like-minded travelers — before, during, and after your trips. Plan together. Meet up. Make the trip.

## Features

- **Find Companions** — Match with travelers headed the same direction based on shared interests, travel style, and compatibility.
- **Plan Together** — Collaborative itineraries, shared wishlists, and group cost splitting — all in one place.
- **Explore Better** — Interactive maps, local insights, and shared experiences to go beyond the tourist trail.

## Tech Stack

- **React 19** with Vite for fast development and building
- **Plain CSS** with CSS custom properties for theming
- **ESLint** with React hooks and refresh plugins

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Motivation

Travel is universal — but meaningful connection on the road shouldn't be left to chance. Traver exists for people who want both: the freedom of independent travel and the richness of doing it with people who actually get them. Not every trip needs company. But when it does — it should be easy to find.
